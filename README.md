# «Сложно сосредоточиться»

Адаптивный лендинг с системой переключения светлой и тёмной тем

## Контекст проекта

**Учебный проект от [Яндекс Практикум](https://practicum.yandex.ru/)**
- **Макет предоставлен:** Яндекс Практикум
- **Задача:** Создать лендинг с системой переключения тёмной и светлой тем

## О проекте

- **Технологии:** HTML5, CSS3 (Grid, CSS Variables), JavaScript
- **Статус:** Завершен
- **Тип проекта:** Адаптивный лендинг с системой тем
- **Демо:** [Открыть проект](https://legion13-alt.github.io/slozhno-sosredotochitsya)

## Техническая реализация

### **Что сделано:**
- **Переключение тем** - ручное переключение между светлой и тёмной темами
- **Автоматическое определение системной темы** - синхронизация с настройками ОС
- **Гибкий текст** - адаптивная типографика, меняющаяся с размером экрана
- **Оптимизированная загрузка картинок** - адаптивные изображения для разных разрешений
- **CSS-переменные** - централизованное управление цветами и размерами

### **Особенности реализации:**
- CSS Grid для сложных раскладок
- CSS-переменные для динамического изменения тем
- JavaScript для управления состоянием интерфейса
- Адаптивные изображения
